# The Problem Behind the Problem

**A chatbot is easy. A reliable chatbot is not.**

```text
User
 ↓
Question
 ↓
Relevant knowledge
 ↓
Reliable answer
 ↓
Sources
```

### Ask

What happens if the model doesn't know the answer?

**It shouldn't hallucinate.**

That's why we're not simply calling an LLM.
