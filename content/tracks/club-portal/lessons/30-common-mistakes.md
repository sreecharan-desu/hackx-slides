# Common Mistakes We Saw

**What went wrong during the hackathon?**

- Keyword search ≠ RAG
- Hardcoding ≠ architecture
- More APIs ≠ better architecture
- More citations ≠ better grounding
- AI-generated code ≠ understanding
- Working UI ≠ complete system
- AWS deployment ≠ production readiness

Patterns — not individuals.
