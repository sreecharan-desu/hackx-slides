# Mapping to AWS

| Component | AWS possibility |
| --- | --- |
| Frontend | S3 / CloudFront |
| Backend | EC2 / ECS |
| Authentication | Cognito |
| Email | SES |
| Documents | S3 |
| Database | RDS |
| Vector search | OpenSearch / suitable vector store |
| Monitoring | CloudWatch |

These are **possible production mappings**, not requirements.

Local deployment is acceptable. Live AWS is bonus.
